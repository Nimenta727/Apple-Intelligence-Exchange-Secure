## 判定规则

- R3/R4 任一未通过：**不能称 Siri→DeepSeek 已实际可用**。
- R5 未通过：**不能称“答案一定来自 DeepSeek”**。尤其脚本未执行和 iOS 回退，不可仅用脚本 502 作为证明。
- R7/R8 必须复核发布 commit、安装模块引用与 Key 清理方式；分支上的测试脚本不等于可用生产插件。
- 版本发布后应记录 commit SHA、Shadowrocket/iOS 版本、模型配置、匿名化验证标记、失败复现和回滚结果。

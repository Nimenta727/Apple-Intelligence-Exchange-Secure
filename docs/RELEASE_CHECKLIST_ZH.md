# AIES v0.6 发布验收清单

> 本表必须记录**实测证据**。当前仅通过离线自动测试；没有真实 Siri 与实际 DeepSeek API 的通过记录。

| 验收项 | 当前状态 | 要求 |
|---|---|---|
| 唯一部署入口和当前文档 | 已实现 | 只有 60 模块、当前脚本与正确链接 |
| 请求解析/关联、SSE 重建模拟 | 离线通过 | 当前测试 fixture、异常路径 |
| DeepSeek Key 与真实 API | **未验收** | 在设备本地授权，使用不敏感问题 |
| 原生 Siri UI 确实显示 DeepSeek 答案 | **未验收** | 不能以日志或网页替代 |
| SSE 分块、压缩、顺序和连续提问 | **未验收** | 无错配、无千问片段 |
| 模型 401/429/5xx、超时/无 Key | **未验收** | 不应展示千问 AI 文本 |
| 脚本缺席、MITM/VPN 断开和系统回退 | **未证明** | 若仍可展示千问，则不能称“始终 DeepSeek” |
| 本地上下文缓存、Key、CA、日志安全 | 待最终审计 | 最小留存、只保留脱敏结果 |
| 稳定版发布 | **未发布** | 必须先通过适用门槛 |

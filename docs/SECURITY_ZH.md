# 安全模型和部署边界

> **实验性质：未通过 iPhone 真机验证。** 请先阅读 [安装配置教程](CONFIGURATION_ZH.md)。

## 设计目标

- 仅允许确实授权的 DeepSeek 官方 HTTPS 目标：\`https://api.deepseek.com/chat/completions\`。
- 在 Shadowrocket 请求脚本里尝试本地返回模拟响应，**不依赖千问正式响应**。
- 没有有效 Key、遇到不支持的输入、HTTP 异常或超时时，代码层面**拒绝**，不会执行 \`$done({})\` 放行。
- 无 \`sair.box\` Web Dashboard，无未鉴权的 \`/config\`、\`/models\`、\`/reset\` 控制接口；不接受从 URL 传入 Endpoint 或密钥。
- 不把敏感内容写入持久化 Prompt 或图片缓存，也不把密钥写入错误消息。
- 以本地审计代码替代自动追踪上游 \`main\` 分支脚本，仓库可公开，但私钥不公开。

## 无法只靠这个插件保证的事

- **VPN 断开 / iOS 绕过网络扩展**：模块无法继续控制流量。
- **客户端执行顺序**：\`REJECT\` 可能优先于 JavaScript，导致安全阻断但不能调用 DeepSeek；反之若脚本执行失败且 REJECT 未生效，也有原始请求泄露风险。
- **系统其它网络路径**：苹果可能通过其他域名或协议（包括 HTTP/3）传输不同的 Apple 智能流量。
- **SSE 完整性**：当前返回的是依据上游公开分析整理的候选 SSE，不是实际设备证明兼容的协议实现。
- **CA 私钥安全**：由 Shadowrocket 管理。iOS 系统对被信任根 CA 授予较广信任，配置里的单域名 MITM 不是操作系统级域名限制。
- **密钥安全性**：\`$persistentStore\` 的存储加密、备份与同步行为取决于具体版本；不能宣称等于 iOS Keychain。

## 核心威胁与措施

| 威胁 | 本项目对策 | 剩余风险 |
|---|---|---|
| 无鉴权配置接口被恶意网页修改 | 删除 Web Dashboard 和配置接口 | 恶意脚本与客户端漏洞仍有风险 |
| 使用任意 Endpoint 发送 Key | 代码中固定 DeepSeek HTTPS Endpoint | 本机恶意软件、越狱设备、被修改的脚本 |
| API Key 回显/URL 泄露 | 不通过 GET URL 存取，示例只含占位符 | 临时初始化脚本、设备备份、客户端存储 |
| 客户端证书或代理过度授权 | 单域名 MITM、设备本地 CA、禁止共享私钥 | 根 CA 信任本身是系统级能力 |
| 失败时向千问透传 | 代码层面失败时 mock 错误 + REJECT 后备 | 客户端可能不按预期运行，尚待实测 |
| 多轮提示词错配 | 不读取全局“最近一次请求”缓存 | 原始请求结构变化、非文本输入不支持 |
| 远程脚本供应链风险 | 本地脚本优先，关闭原 SAIR | 用户自行导入未审计模块仍危险 |
| DeepSeek 费用和隐私 | 低额度专用 Key、仅必要文本发送 | 云端处理由 DeepSeek 服务商完成 |

## 私有化的准确含义

这份代码拥有自主维护的副本和明确授权的 DeepSeek API 目标，**不依赖 SAIR 作者的业务服务器**；不是离线运行的 AI。DeepSeek 会收到用户发送的内容。若要“完全私有推理”，需要将后端迁移到本人控制的可信私有模型服务，并重新审计域名/证书/通信链路。

## 发布与许可证

保留原项目作者 boitar 的 MIT 许可证文本和著作权声明。本项目不是 Apple、Shadowrocket 或 DeepSeek 官方项目。公开 GitHub 仓库不得承载任何实际 API Key、CA 私钥、设备配置备份、请求体抓包文件。

## 发生泄露时

1. 在 DeepSeek 官方后台**立即撤销**对应 API Key。
2. 停止实验模块、启用阻断基线并核查有效规则。
3. 如果怀疑 CA 私钥泄露，在 iOS 取消信任、卸载证书，重新生成新的 CA。
4. 清理带密钥临时脚本、备份、日志，检查仓库提交历史（仅删除文件不等于删除 Git 历史）。
5. 如果曾将 Key 提交到 GitHub，即使删除或改成 private，也应**立即吊销 Key**。


## 0.2.0-lab 二次工程审计补充

已将原单体脚本拆分为受测的协议解析、模型调用、SSE 和响应状态机。增加生成脚本一致性检测、异常网络响应、重复回调、超时后迟到回复及不合法输入的单元测试。密钥继续由客户端本地脚本存储管理，不提供网络控制接口。

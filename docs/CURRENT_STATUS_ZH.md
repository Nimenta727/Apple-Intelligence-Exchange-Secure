# AIES v0.6 当前状态

> **当前版本：v0.6.0-beta（`main`）。候选代码和离线回归已完成；真实 Siri UI 和实际 DeepSeek API 尚未验证。**

| 环节 | 现状 |
|---|---|
| 唯一 Shadowrocket 60 模块与双钩子 JS | 已编码 |
| 文本识别、会话关联、SSE 重建 | 已编码、离线模拟通过 |
| DeepSeek API 对接 | 已编码；模型 `deepseek-flash` 的实际可用性未核实 |
| 请求/响应钩子在真实 Siri 上是否触发 | 未验证 |
| Siri 原生界面是否接受重建 SSE | 未验证 |
| 分块、压缩、超时、并发和快速连续提问 | 需真机验证 |
| DeepSeek 失败时是否完全没有千问回退 | 脚本内部尝试阻止，系统级未证明 |
| 本地短期问题正文存储与彻底清理 | 待安全改善 |
| 稳定版 Release | **未发布** |

产品支持范围：特定 Siri 文本问答，不支持写作工具、视觉智能、音频文件、多模型或本地离线模型。用户接受原始请求可能由千问处理，DeepSeek 也会收到问题。

当前下一步：按 [安装指南](INSTALL_SIRI_DEEPSEEK_V06_ZH.md) 做一次集中真机验收，按 [调试说明](DEBUGGING_ZH.md) 判断是宿主钩子、SSE、DeepSeek 还是原生 Siri UI 环节失败。达到 [发布清单](RELEASE_CHECKLIST_ZH.md) 的门槛后再决定是否发布稳定版。

仓库只保留当前 v0.6 的运行文件、测试与文档，不再维护不相关的旧实验代码。删除仓库中的旧文件**不等于清除设备上此前导入的模块**，实际设备仍需停用冲突配置。
